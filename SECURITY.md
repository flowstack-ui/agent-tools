# Security Policy

## Supported versions

Security fixes are made for the latest published versions of
`@flowstack-ui/agent-tools` and `@flowstack-ui/mcp`. Older releases may remain
affected after a fix is available.

## Report a vulnerability

Do not open a public issue. Submit a
[private security advisory](https://github.com/flowstack-ui/agent-tools/security/advisories/new)
with the affected package/version or hosted route, realistic impact, a minimal
reproduction, relevant client/runtime versions, and any disclosure constraints.
Remove credentials, tokens, private data, and unrelated secrets.

Maintainers will acknowledge the report, validate impact, coordinate a fix and
release when necessary, and discuss disclosure and credit with the reporter.

## Scope

In scope are vulnerabilities in the published npm packages, skill/plugin
archives, public generated corpus, and hosted MCP endpoint. Documentation
mistakes without security impact, unsupported versions, third-party services,
and scanner-only findings without credible impact or reproduction are
generally out of scope.
